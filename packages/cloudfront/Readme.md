# CloudFront

本リポジトリはCloudFrontを管理するCloudFormationテンプレートを提供します。

## 各種手順

```bash
################################################################
# スタック名の作成
################################################################
# サービス名
# 環境ごとにユニークなものを設定する
SERVICE=<サービス名>
# スタック名
STACK_NAME="${SERVICE}-g1"
```
