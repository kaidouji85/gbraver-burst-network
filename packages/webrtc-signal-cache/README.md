# Signalキャッシュサーバー

本サーバーはWebRTCのシグナリングデータをキャッシュするためのサーバーである。
GブレイバーバーストのWebRTCではQRコード読み取りにより手動でシグナリングデータを交換するが、
SDP、ICE CandidateはQRコードには収まりきらないため、シグナリングデータを一時的に保存するサーバーが必要となる。

## コマンド例のカレントディレクトリについて

とくに断りがない限り、本書のコマンド例のカレントディレクトリは`<本リポジトリをcloneした場所>/packages/webrtc-signal-cache`であるとする。

## 前提条件

プロジェクトルートに記載されている[前提条件](../../Readme.md#pre-required)をクリアすること。

## 各種コマンド

### デプロイ

```shell
npx sls deploy --stage <ステージ名>
```

### 環境破棄

```shell
npx sls remove --stage <ステージ名>
```
